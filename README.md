# Автоматическая детекция дефектов ткани (YOLOv8-Nano)

Система компьютерного зрения для локализации и классификации промышленного брака ткани в режиме реального времени. Проект ориентирован на развертывание на маломощных edge-устройствах, смартфонах и встраиваемых платформах контроля качества на текстильном производстве.

## 🎯 Бизнес-задача и технические особенности
* **Цель проекта:** Автоматизация контроля качества на конвейерной ленте для снижения процента производственного брака.
* **Выбор архитектуры:** Использована компактная модель **YOLOv8 Nano** (Ultralytics), обеспечивающая минимальное потребление памяти и высокую скорость инференса.
* **Классы дефектов:** Модель обучена распознавать 4 типа брака:
  * `Cassure` — надрывы ткани.
  * `Tache` — пятна и загрязнения.
  * `defaut` — общие дефекты структуры.
  * `Fil tire ou gros` — затяжки нитей.

## 📊 Результаты и метрики
Модель прошла процедуру тонкой настройки (Fine-tuning) на специализированном датасете *Fabric Defect* в течение 35 эпох.

* **Итоговый вес модели:** 6.2 МБ (оптимально для мобильной интеграции).
* **Скорость обработки:** ~7.2 ms на один кадр.
* **Качество детекции (mAP@0.5):** Модель демонстрирует стабильные результаты при обнаружении крупных и контрастных дефектов. Ограничения Nano-версии (пропуски бледных или слишком мелких зацепок) являются осознанным компромиссом в пользу колоссальной скорости работы алгоритма.
